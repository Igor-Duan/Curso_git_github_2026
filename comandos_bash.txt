ls -> lista os arquivos
cd -> move entre diretorios
pwd -> mostra o proprio diretorio
cat -> exibe conteudo do arquivo
rm -> remove arquivo do diretorio
rm -rf -> remove todos os diretorios de forma recursiva e forçada.
