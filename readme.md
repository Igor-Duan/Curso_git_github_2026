##Fluxo De Trabalho Git Local:

01- git checkout -b "nova branch"
02- atualiza ou criar a arquivios
03- git status
04- git add . "adicionar qlq tipo de arquivo"
05- git status
06- git commit -m "commit e (minha msg)"
08- git checkout main
09- git merge outra_branch


## Fluxo De Trabalho GitHub <> local (projeto proprio ou da empresa)

01 -git clone <endereco do projeto>
02 -git checkout -b "nova branch"
03 -alteracoes do arquivo
04 -git status
05 -git add .
06 -git commit -m "commit e (minha msg)"
07 -git push origin (nova_branch)
08 -abrir pull request no GitHub para a main
09 -excluir (nova branch) origin
10 -git checkout main
11 -git branch -D (nova branch)
